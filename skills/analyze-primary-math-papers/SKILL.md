# 小学数学试卷分析

## 目标

依据试卷照片中实际可见的题目、学生作答和批改痕迹，形成准确、温和、可操作的分析。重点识别数位与概念理解、表示与解题方法、检查与表达习惯等数学学习过程。把图像识别、教师批改、独立验算和错因推测分开；不要把模糊内容或猜测写成事实。

本 Skill 只负责识别、核对和分析，不出练习题。用户需要变形题或测试卷时，把本 Skill 产出的“已确认错题清单”交给 `$make-primary-math-variant-test`。

## 先识别，再请用户核对错题

1. 按页码和题号整理题干、必要图形或表格信息、学生答案、批改标记。多张照片注意同一道题跨图、漏拍和重复。能看清才转写；看不清的数字、符号、单位、步骤或批改标记标为“待辨认”，请用户补拍局部或转述。不要靠题型猜原题。
2. 根据批改痕迹和独立验算，初步区分“做对”“疑似做错”“无法判断”。教师标记与数学验算不一致时列出分歧；部分得分、未作答、改过答案也单独说明。没有评分标准时，不推定扣分或总分。
3. **在分析任何错题之前，先向用户展示疑似错题核对清单，并等待用户明确确认或更正。** 每项至少含页码/题号、识别出的关键题干、学生答案、批改结果或疑点；较长题干可摘要，但影响解题的条件必须完整。可用“请核对：这些题是否确实做错？题干、数字和孩子的答案有无识别错误？请按题号更正或回复确认。”不要把用户的沉默当成确认。
4. 用户更正后以更正内容为准，必要时重新验算；只对已确认且信息足够的错题作定论。若用户指出某题其实做对，把它移至做对题；若批改可能有误，说明独立验算过程并请用户核实原卷，不替老师擅自改分。无法确认的题保留“待核对”，不作错因诊断。

## 分析方法

- 表扬数学学习中有价值的行为：抓住限制条件、用数位或图示表示问题、解释理由、比较与验算、把方法迁移到新题。每一点都要指向题号及可见证据。只有选项或答案时，可肯定该题的正确结果和它涉及的数学想法，不能声称孩子实际采用了某种思路、具备稳定能力或某种性格品质。
- 对每道确认的错题先独立解题并复核答案，再写清核心数学关系、正确解法和关键检查点。分析时分三层：**已观察到的行为**（原答案、步骤、漏写内容），**可能机制**（概念或题意理解、表示与解题方法、检查与表达习惯），**还需什么证据**。不要把“粗心”“不会”当作原因；看不到过程时只能列待验证假设。
- 判断机制要用能区分的证据：能否用自己的话解释条件与数位、能否用数位表或边界数完成同类题、能否发现他人的错误、独立重做时是否仍漏符号或不检查。一次答案或一次口头解释不足以给孩子贴标签；习惯问题尤其要在“理解和方法已过关”后才判断。
- 解释适合相应年级，优先用孩子能理解的步骤、示意或数值核验，不超出原题所需知识。若年级未知，按试卷内容选择表达深度，不必仅为年级追问。
- 面向国内小学数学试卷，数的书写遵循万级、个级等四位分级习惯：正文可写连续数字（如40108740），讲数位时可写“4010 8740”。不要套用三位一组的英文逗号格式。家长报告优先用短小节呈现每题的事实、待验证原因和后续观察点，避免一张过宽的密集表。
- 优先分析错误背后的共性，但逐题保留原题号。统计只覆盖可识别、已核对的范围，注明未识别或待核对题，不虚构正确率、分数和能力结论。

## 交付

完成确认后交付一份**试卷分析报告**（Markdown 或用户指定格式的独立文件）。报告统一放在不带日期的目录 `output/primary-math-paper-analysis/` 中；文件名以分析日期开头，如 `20261014-试卷分析报告.md`。同一天分析第二份时，在日期后加序号（如 `20261014-2-试卷分析报告.md`），不要覆盖已有文件。报告依次包含：

1. 开头用 3～4 句给家长总结已确认错处的两三条学习主线与最重要的待验证问题。主线可以交叉覆盖同一题，但不要把单次错误写成已证实的能力缺陷。
2. 识别与确认范围、有证据的数学学习亮点。
3. 逐道错题的“观察—假设—验证”分析，以及可操作的复习建议。
4. 待核对项。
5. **已确认错题清单**（放在报告末尾，供出题使用），每道错题一条，固定包含：
   - 来源：页码/题号
   - 原题：完整题干（含图形、表格的文字描述和单位）
   - 孩子答案与正确答案
   - 核心知识点
   - 待验证的错因假设（理解 / 方法 / 检查表达，可多选）

报告最后一句提示用户：如需针对这些错题出变形题测试卷，可使用 `$make-primary-math-variant-test`。不要在报告中附带练习题。

写文件后检查错题题号、正确答案与清单是否一致，统计范围是否注明待核对题。未得到错题确认时，当前轮只交付核对清单并等待回复，不提前生成错误分析。
