# 少儿科普介绍与语音

## 核心目标

面向9岁及以上儿童解释一个真实的科学主题，同时交付准确易读的文字版和完整的中文语音版。默认适合9—12岁；按用户指定年龄调整词汇、知识深度和篇幅，不降低事实标准。

## 默认设置

- 采用一个明确主题，约1200—1800字，语音约6—10分钟。
- 使用简体中文，以科普介绍为主，不默认设置会说话的动植物、冒险情节或虚构角色。
- 语气亲切、平静、有好奇心，避免幼稚化和教科书式堆砌。
- 用户未指定声音时，使用自然温和的普通话女声、稍慢语速和清晰停顿。
- 只有年龄、主题或关键限制会实质改变结果时才提问；否则直接制作。

## 工作流程

1. 确定一个核心问题，例如“种子怎样萌发”“萤火虫为什么发光”。
2. 列出内容依赖的4—8个核心事实，按 [事实核验规则](references/fact-checking.md) 判断是否需要检索。
3. 先写适合阅读的科普介绍，再改写成适合朗读的语音稿。
4. 删除语音稿中的链接、引用标记、复杂括号、表格和不自然的项目符号；把单位、缩写和生僻术语改成听得懂的表达。
5. 使用可用的原生或已连接文本转语音能力生成MP3。没有现成能力时，可调用 `scripts/generate_audio.py`；运行前确保安装 `edge-tts`。
6. 检查音频能正常解码、时长合理、声音不削波且不是静音。
7. 同时交付文字内容和音频文件，不要只给朗读稿或制作方法。

## 科普结构

按主题灵活组织，通常包含：

1. **从现象开始**：用一个孩子能观察到的问题引入主题。
2. **先给结论**：用一两句话回答核心问题。
3. **解释原理**：按时间、结构或因果顺序拆解过程，一段只讲一个要点。
4. **澄清误区**：指出1—2个常见但错误或不完整的说法。
5. **联系生活**：说明如何观察、保护或应用这项知识；不提供危险实验。
6. **自然收束**：总结核心规律，并留下继续探索的方向。

科普正文可以使用比喻，但紧接着说明真实机制，不能让比喻替代事实。故事化场景只能用于短暂导入，不能虚构证据、能力或科学结论。

## 默认文字输出

依次输出：

1. 标题
2. 适读年龄、预计阅读与收听时长、主题
3. 科普介绍正文
4. **核心知识**：4—6条准确结论
5. **常见误区**：1—2条
6. **想一想**：2个开放式问题
7. **事实依据**：进行了检索、用户要求来源或主题容易误解时，列出2—4个权威来源链接
8. MP3语音文件

正文中的引用放在段落末尾，不要让引用打断朗读稿。音频只朗读标题与科普正文；除非用户要求，不朗读来源链接和思考题。

## 语音制作

- 优先使用自然、清晰的普通话语音；默认语速比正常对话慢约10%—15%。
- 将长句拆短，为标题、转折、因果链和段落结尾保留停顿。
- 正确处理多音字、数字、单位、英文缩写和专业词；必要时在语音稿中改用中文全称。
- 文件名使用安全、清晰的格式：`主题_少儿科普.mp3`。
- 若使用脚本：`python scripts/generate_audio.py 输入稿.txt 输出.mp3`。可用 `--voice`、`--rate`、`--pitch`、`--volume` 调整。
- 生成后用音频检查工具确认可解码，并检查时长与音量。失败时修复并重新生成，不交付空文件或损坏文件。

## 事实与安全

- 不编造实验、论文、科学家、机构、物种、纪录或历史事件。
- 不把相关性写成因果，不用“所有、从不、一定、唯一”等绝对词掩盖例外。
- 对争议、证据有限或因物种与环境而异的结论，使用“目前证据显示”“通常”“可能”“在某些情况下”等限定。
- 不提供危险家庭实验、野生动物接触、食用辨认或替代专业人员的医疗建议。
- 客观解释捕食、寄生、疾病、灾害等主题，不制造恐慌或给动物贴“好坏”标签。

## 最终检查

- 核心问题已明确回答，解释顺序清楚。
- 事实、数字、单位、范围、时间尺度和因果链准确。
- 比喻与真实机制边界清楚，没有把虚构写成事实。
- 词汇和深度适龄，专业术语均得到解释。
- 文字版适合阅读，语音稿适合听觉理解。
- MP3完整可播放，内容与最终科普正文一致。
