# 使用示例与行为核验

这份文件用于把握检验卡的尺度和检查边界。示例中的儿童回答只用于演示判读，不是用户孩子的记录。不要把示例中的词、人物或答案套入别篇文章。

## 完整原文输入示例

用户：

> 四年级，今天读了下面这篇短文，摘了最后一句，帮我准备今天的检验。

以下是本技能自拟的原创演示短文《借伞》，不是教材课文：

> 放学时，雨突然下大了。小禾站在教学楼门口，攥着书包带，望着远处的公交站。
>
> 同桌小林撑开伞，对她说：“一起走吧。”小禾犹豫了一下：“可是你家在另一边。”小林笑了：“先送你上车，我再回去。”
>
> 到了站台，小禾才发现，小林靠外侧的肩膀湿了一片。他一路把伞往她这边偏，自己却没有说什么。

可交付的检验卡：

**《借伞》｜依据你提供的完整短文｜四年级｜约4分钟，计入原有半小时。**

给孩子的两个问题：

1. 你觉得小林是怎样的同学？选一处文中的表现，说说你的理由。可以翻书。（约2分钟）
2. 你摘了最后一句。如果只写“小林很关心小禾”，和这句话相比，你更喜欢哪种写法？为什么？（约1分钟）

家长备忘，提示和反馈预留约1分钟：

- **第1题，看能否根据行为解释人物。** 说“关心同学”“愿意帮助别人”等均可；依据可以是绕路先送小禾上车，也可以是把伞偏向小禾导致自己肩膀淋湿。只报性格词，还需要补依据。先提示“想想他走的路或伞偏向哪边”；仍困难，一起重读相应句子，示范“他自己淋湿了，还把伞偏向小禾，所以我觉得他关心同学”。
- **第2题，看能否解释摘抄价值。** 喜欢原句，可以说动作让我看见小林怎样照顾同学；喜欢直接表达，也可说它简洁、清楚。重点是说出与具体文字相关的理由，不以选哪一句判对错。先提示“你读到这句话，脑海里看见了什么”；仍困难，一起读“把伞往她这边偏”，示范动作怎样表现关心。
- 两题分别记“独立完成／提示后完成／还需帮助”；未问不记不会。可以反馈：“你找到了伞偏过去这个动作，理由说得很具体。”只说实际出现的表现。

**隔2—3天回顾，替代那天的第2题：** “同桌邀请你一起上台表演，你想参加，又有点担心。用‘犹豫’说一句话。”能表现想做又拿不定主意即可，不要求字典释义或固定句式。

可选记录：`《借伞》｜根据行动解释人物｜____｜下次只看：____`。

## 材料不足时

用户：“今天读了《秋天》，准备一下。”

- 先用现有上下文或可用检索区分同名材料；若仍无法确认，回复：“《秋天》有同名作品。请给我作者或今天读的那一页，我就能把题目和参考要点对应到原文。暂时可先聊：‘你读到的秋天有哪些具体景物？选一处，说说你想到的画面。’这只是通用提问，具体题目待原文补齐。”
- 不凭书名指定作者、编造一句秋景、引用别的年级课文，或提供未经核实的标准答案。

用户：“今天读《西游记》，帮我检验。”

- 询问今天读的章节或片段；可读附件时先读取附件。不默认检查取经全过程，不用后文内容做答案。

## 发布前人工情境检查

用技能实际处理下列请求，对照结果检查决策。它们是验证场景，不是日常必须交付给用户的题单，也不能仅靠关键词匹配宣称行为通过。

| 场景 | 应观察到的行为 |
| --- | --- |
| 使用上面的完整原创短文 | 直接产出绑定情节的两个问题，答案及证据正确；总用时包含提示反馈，未来回顾单列。 |
| 提供两段科普说明文 | 根据这两段检查解释、因果或比较；不用“主人公是什么心情”硬套文体，不查后文补题。 |
| 同名文章，仅有标题且无法核实版本 | 索取最少的消歧材料，不捏造文本细节和篇目专属答案。 |
| 仅有书名、尚不知阅读进度 | 确认已读范围；没有未读情节泄露。 |
| “今天没时间，只用2分钟” | 缩成一个主问题，不叠加必答的听写、仿写和旧题。 |
| 已有当天两个问题，用户提交孩子回答 | 只评实际答案；不知道是否有提示时不擅自记独立，指出一个具体下一步，不重新出整卡。 |
| “帮我出一周回顾”，但没有历史 | 说明缺少旧记录，使用已知材料或索取范围；不编造上周错词，不输出整套考试卷。 |
| “今天推荐一篇阅读并配题” | 给可取得并已核实的适龄材料，或明确标为原创的短文；题目依赖的正文可见，不假装知道学校进度。 |
