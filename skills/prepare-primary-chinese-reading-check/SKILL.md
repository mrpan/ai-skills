# 小学语文每日轻量检验

## 家庭默认设置

- 孩子四年级，每天已有约30分钟阅读与摘抄。检测安排在这30分钟内的最后3—5分钟，以口头交流为主，不追加一轮书面作业。
- 用户更新年级、可用时间、阅读范围或任务要求时，以最新信息为准。不反复询问已经给出的年级与习惯。
- 每次交付可直接照着问的内容，观察“读懂、保留、运用”的具体表现。每日只抽样，长期能力要结合多次表现；计划用时是估计，不声称已实测或有统一达标线。
- 默认两个主问题：一个阅读理解问题，一个字词或摘抄表达问题。追问是同一题的可选提示，不得变成额外必答题。到点结束，顺利完成也不临时加题。

## 先确定今天实际读了什么

优先读取当前对话、附件、用户指定的本地文件或链接中的原文。能读取现有材料时，不让用户重复提交。

| 输入情况 | 处理方式 |
| --- | --- |
| 提供原文、清晰照片或明确节选 | 直接按可见内容出题；照片中不清楚的关键字句标为待核对，绕开存疑部分，不猜字出题。 |
| 只给文章名或课文名 | 尝试查找可靠原文，优先作者、出版社、官方教材或教育机构来源。核对作者、版本和节选范围；教材中的删改、自然段编号和生字要求不能从别的版本套用。 |
| 找到全文，但不知道今天读到哪里 | 短篇可以注明“暂按全文准备”；长篇或整本书需确认章节、页码或已读片段，不能把后文情节用于提问或答案。 |
| 标题有歧义、版本不明且会影响出题，或原文查不到 | 用一句话索取能消除歧义的最少材料，例如作者、相关页照片或已读段落。可同时给一个明确标注“待原文补齐的通用提问”，但不编造具体词句、人物、答案和段落依据，也不把它称为已完成的篇目检验。 |
| 用户问“今天读哪篇”，明确请你推荐 | 选择篇幅和难度合适、正文可核实且便于取得的材料，给出获取方式并配套出题；用户允许或无合适材料时可写一篇明确标注为原创的短文。若只是询问学校今天学哪课，不能假装知道课表，先询问课程信息。 |

收到足够的节选即可推进，不必为了全文或完整教材信息继续追问。只覆盖实际核实的范围，并明确范围；用户有链接而工具无法访问时如实说明。若用户只提供孩子今天的回答，优先利用对话中已有原文与题目。

## 准备当天的两个问题

先从原文选定一个阅读目标和一个积累运用目标，再写问题。不要先列通用题型再硬套文本。

### 问题一：阅读理解，约2分钟

按文体和篇幅选一个最有价值的观察点：

- 叙事：主要事件、人物遇到的问题与变化，或从动作、语言推断心情和动机。
- 写景与散文：描写对象、观察顺序、具体语言呈现的画面或感受。
- 科普与说明文：解释的现象、关键因果、步骤或比较关系。观察能否用自己的话解释，不强行寻找人物和中心思想。
- 诗歌：诗中画面、关键词和情感依据，不强求唯一感受或背诵整首。

概括与推断可以轮换，不要求每天同时完成。问法具体、适龄，少用术语。概括不以完整复述细节为标准，推断需分清文本事实和合理解释；预测没有唯一答案。

需要依据时，可以问“你从哪里看出来的”，允许孩子翻书定位。理解检查采用开卷找依据；需要观察记忆时，可先请孩子尝试回想，再提供线索，不能把背不出原句等同于不理解。

### 问题二：积累运用，约1—2分钟

只选下面一种，不把识字、听写、解释、造句、赏析和仿写全部叠加：

- **字词**：从原文中选一个值得掌握的词，检查语境中的意思，或换个生活情境口头使用。观察写法时可抽查一个本课要求会写的词，并替代当天其他积累题；没有生字表依据时不能声称某字属于本课会认或会写要求。
- **摘抄**：优先使用孩子实际摘抄的句子，问为什么选、哪个词让画面更具体、怎样理解。没收到摘抄内容时，可从原文推荐一句，明确它是建议，不假装孩子已经摘过。
- **表达迁移**：借一个词或一种简单表达方式，口头描述熟悉的生活场景；不要求强行套用原句，不默认写一段作文。

有对话中的旧题或学习记录时，可以用一次延迟回顾替代问题二。没有历史时，按当前文本选择，不推断孩子上次错过什么，不机械依照星期安排任务。

## 给家长可用的判读与帮助

两个问题分别配套以下信息，放在家长区，不混进给孩子的题面：

1. **观察点与参考要点**：写清观察什么，给出足够具体的答案要点及对应段落或句意。允许合理的同义表达和有依据的不同理解；开放题给可接受表现示例，不要求照背。只在需要定位时短引原文，不大段重印受版权保护的材料。
2. **两级提示**：先给线索，如人物、事件顺序或相关段落；仍困难时一起重读关键句并示范。提示要逐步增加支持，不一开始泄露答案，也不连续追问直到孩子疲惫。
3. **状态判读**：按“独立完成／提示后完成／还需帮助”记录本题表现；另有“未观察”，用于当天未问或信息不足。不能把“没回答”自动判为不会，也不把一次正确写成长期掌握。
4. **即时反馈**：指出一个具体做得好的地方，必要时只纠正一个关键点。若答不上来或答错，简短解释后结束，不罚抄、不临时加题。区分观察与原因猜测，避免“粗心、理解差、懒”等标签。

若用户后来发来孩子的回答，先核对原题与文本依据，再简短报告实际表现、使用了什么提示和一个下一步。未说明是否得到提示时，不擅自认定独立完成。参考答案只是备课材料，不是孩子的实际学习记录。

## 默认交付形态

直接在聊天中给一张简短检验卡，通常约500—800汉字，按复杂度缩短；不重复长篇学习理论，不默认生成文件、试卷或打卡工具。

1. **范围与用时**：篇名、已核实的章节或节选、四年级、预计3—5分钟。若依赖网络原文，附可访问的直接来源链接；只有用户原文时写明“依据你提供的节选”。
2. **给孩子的两个问题**：只放自然的提问，不放答案。建议时间总计不超过5分钟，包含必要提示与反馈；作业繁重或用户只剩2分钟时缩到一个主问题。
3. **家长备忘**：对应两题的参考要点、文本依据、两级提示和状态判读，保持精简。
4. **以后回顾，不是今天加做**：从今天的词句或理解目标中选一道20—30秒回顾题，给简短判读要点，建议隔2—3天替代当天问题二；必要时一周后换情境再看，间隔可调整。不要自动安排提醒或声称会跨会话记住。
5. **可选的一行记录**：`篇目｜本次重点｜独立/提示后/还需帮助/未观察｜下次只看什么`，留待实际作答后填写，不预填能力结论。默认建议家长自行简记，不要求孩子填表。

用户主动要求周回顾时，准备约8—10分钟的回顾，替代当天检测并计入原有30分钟。使用难度相近、未做过的短片段，抽查概括或依据，再回顾少量旧词，避免扩成周考试。没有旧记录时明说，并只基于已知内容准备。

需要把握输出尺度、材料不全的处理或验证案例时，读 [references/examples.md](references/examples.md)；解释方法依据或用户要求研究来源时，读 [references/learning-basis.md](references/learning-basis.md)。

## 交付前核对

- 两个主问题均绑定已核实内容，答案、原词和定位依据对应同一篇及同一版本；不剧透未读部分。
- 本日问题、可选提示与未来回顾清楚区分，必要步骤总量能在用户时间预算内完成。
- 开放题允许合理异答；记忆、理解、表达和书写的观察没有混为一谈。
- 家长能看懂怎么判断、怎么帮助；孩子题面不泄露答案。
- 没有虚构教材要求、孩子表现或历史记录，没有用单次抽样宣称整体语文水平。
