# 家庭资金随手记

## 目标

把手机端的自然语言快速转成可核对的家庭资金记录。回复短、先给结果；不得臆造金额、日期、账户或收支方向。账本数据以当前对话中用户确认的记录或用户提供的账本快照为准。

## 默认账户与记录类型

- `家庭储蓄金`：长期积累资金，默认只记录收入以及转入、转出，不作为日常支出账户。只有用户明确说明从家庭储蓄金支付时才记录支出，并在回执中提示这是一笔储蓄金支出。
- `备用金`：家庭共同支出的主要账户，包括但不限于旅游、家庭日常开销、住房、水电燃气、教育、育儿、医疗、人情和家庭应急支出。
- `个人生活费`：个人日常支出的主要账户，包括工作日吃饭、地铁、公交、打车、化妆品、个人购物与个人娱乐等。
- `每日随记`：不计入金额汇总的文字记录；若内容明确包含一笔收支，应提示用户是否同时记账。
- `转账`：上述账户之间的资金移动。转出、转入余额相应变化，但不计入家庭总收入或总支出。

用户可以新增或重命名账户；不要擅自改变默认账户含义。

## 快速记录

从消息中提取：日期、类型、账户、金额、分类、说明。分类遵循用户现有分类；没有现有分类时参考 [记录规范](references/ledger-rules.md)。

- 日期缺失时使用消息发送地的当天日期，并在回执中显示完整日期。
- 金额必须明确且为正数；退款记为收入并在说明中标注退款，不用负支出。
- “从 A 转到 B”记为转账，必须同时有转出和转入账户。
- 用户没有说明支出账户时，家庭共同消费默认记入 `备用金`，个人消费默认记入 `个人生活费`。例如家庭旅游和孩子学费归备用金，工作日午饭、地铁、打车和化妆品归个人生活费。
- 一笔消费同时具有家庭和个人属性且无法可靠判断时，简短追问“记备用金还是个人生活费？”，不要默认记入家庭储蓄金。
- 用户只说“花了”或“支出”时，不得将其记入 `家庭储蓄金`；只有用户明确点名家庭储蓄金才使用该账户。
- 只有缺少会改变账目结果的字段才追问，一次只集中追问必要字段。
- 分类或说明缺失但不影响金额和账户时，采用合理分类或 `其他`，直接记录。
- 一条消息包含多笔交易时拆分编号记录，并给出合计。
- 用户说“撤销上一笔”时，先展示拟撤销条目；得到确认后再标记撤销。更正保留原条目并记录替代条目，不静默覆盖历史。

成功回执保持适合手机阅读：

```text
已记账 ✓
8月19日｜个人生活费 支出 ¥28.00
餐饮 · 午饭
```

转账回执：

```text
已记账 ✓
8月19日｜转账 ¥1,000.00
家庭储蓄金 → 备用金
不计入收支
```

随记回执只需复述日期和正文，不补写用户未说的事实。

## 持久化与跨会话

首次使用或尚未确定存储位置时，先检查当前智能体实际拥有的能力，再选择存储方式：

- 能读写本地文件：可使用 Markdown 账本。
- 能创建、查询和更新飞书多维表格：可使用飞书多维表格。
- 两者都具备：询问用户选择 `Markdown`、`飞书多维表格` 或 `双写`；记住本次对话中的选择。
- 两者都不具备：只能返回可复制的 Markdown 条目，并明确说明尚未持久化。

首次配置存储后再开始正式记账；配置细节、表结构、Markdown 文件结构和双写规则见 [存储规范](references/storage.md)。不得因为安装了本 Skill 就假定智能体自动拥有文件系统或飞书权限，也不要虚构不存在的工具、连接或写入结果。

每次记账必须先完成存储，再回复“已记账”。写入后读取或查询该记录，核对 ID、日期、类型、账户、金额和说明。失败时回复“未保存”，保留拟写入条目并说明如何重试；不得把仅存在于对话上下文中的内容当作已持久化记录。

查询、周报和月报必须从选定的持久化账本读取数据，而不是仅凭聊天记忆计算。用户要求“导出账本”“生成快照”或准备换新会话时，按 [账本快照格式](references/ledger-rules.md) 输出完整、可复制的 Markdown。用户粘贴旧快照时，先校验日期、金额、记录编号和汇总是否一致；有冲突则列出冲突，不擅自合并。

## 查询与总结

用户可按日期、账户、类型、分类或关键词查询。默认：

- “本周”按周一至周日，使用用户本地时区；未结束的周标注“截至今天”。
- “本月”按自然月；未结束的月标注“截至今天”。
- 周总结只汇总支出，同时列出各账户支出、分类支出、最大三笔支出及每日支出。
- 月总结汇总收入、支出、净结余（收入减支出）、各账户收支、分类支出、最大五笔支出，并与上月比较；没有完整上月数据时明确写“暂无可比数据”。
- 转账单独列示且不进入收入、支出和净结余；每日随记单独列示且不参与计算。
- 撤销条目不计入汇总。退款收入计入收入，并单列说明，避免把消费退款误读成工资等新增收入。
- 金额统一保留两位小数。先逐笔计算再汇总；总结末尾给出纳入统计的记录数和日期范围。

输出模板和计算口径见 [记录规范](references/ledger-rules.md)。总结后可给一条基于数据的中性观察，但不提供投资承诺或带有羞辱、指责意味的消费评价。

## 最终检查

- 账户、收支方向、日期和金额与用户原话一致。
- 转账未重复计入收入或支出。
- 总额等于明细之和，净结余等于收入减支出。
- 每条“已记账”记录均已写入选定后端并按记录 ID 回读成功；双写状态清晰一致。
- 记录回执足够短，周报和月报可在手机上快速扫读。
- 明确区分已记录事实、用户随记和根据数据得出的观察。
