# 存储规范

仅在首次配置存储、执行读写、同步、迁移或排查存储问题时读取本文件。

## 能力检测与选择

检查当前智能体可调用的工具，不凭工具名称猜测权限：

1. Markdown 模式需要能够创建、读取和更新用户授权位置中的文本文件。
2. 飞书多维表格模式需要能够创建或访问多维表格、读取字段与记录、创建记录并更新记录。
3. 如果工具只读，则不能把该后端作为主存储。
4. 如果用户提供现有文件路径或多维表格链接，优先使用该位置；写入前先读取结构和少量现有数据。
5. 不自动安装外部连接器、登录账号或申请权限。缺少能力时说明缺少哪项能力，并提供 Markdown 可复制记录作为降级方案。

Skill 本身不绑定特定智能体或平台依赖。安装到不同智能体后，按其实际工具能力执行上述检测；不支持飞书的智能体仍可完整使用 Markdown 模式。

## Markdown 模式

默认建议文件名为 `家庭资金账本.md`，但用户指定的目录和文件名优先。文件使用 UTF-8，结构如下：

```markdown
# 家庭资金账本

## 配置

- 币种：CNY
- 时区：Asia/Shanghai
- 周起始日：周一
- 存储模式：Markdown

## 记录

| ID | 日期 | 类型 | 账户/流向 | 金额 | 分类 | 说明 | 状态 | 创建时间 | 更新时间 |
|---|---|---|---|---:|---|---|---|---|---|
| 20260819-01 | 2026-08-19 | 支出 | 个人生活费 | 28.00 | 工作日餐饮 | 午饭 | 有效 | 2026-08-19 12:30:00 | 2026-08-19 12:30:00 |

## 每日随记

| ID | 日期 | 内容 | 状态 | 创建时间 |
|---|---|---|---|---|
| 20260819-N01 | 2026-08-19 | 今天决定减少外卖 | 有效 | 2026-08-19 21:00:00 |
```

写入要求：

- 新文件先写入配置和空表头，再加入第一条记录。
- 更新现有文件前先读取最新内容，按 `ID` 检查重复；同一 ID 且内容一致视为幂等成功，内容不同视为冲突。
- 保留用户在文件中的其他章节和注释，不用整份重写破坏无关内容。
- 更正和撤销按记录规范追加记录或更新状态，保留审计痕迹。
- 写入后重新读取目标条目并核对关键字段。

## 飞书多维表格模式

建议创建名为 `家庭资金账本` 的多维表格，包含两个数据表。

### 收支明细

| 字段 | 推荐类型 | 规则 |
|---|---|---|
| 记录ID | 单行文本 | 唯一键，例如 `20260819-01` |
| 日期 | 日期 | 交易日期 |
| 类型 | 单选 | 收入、支出、转账、撤销 |
| 账户 | 单选 | 家庭储蓄金、备用金、个人生活费 |
| 转出账户 | 单选 | 仅转账填写 |
| 转入账户 | 单选 | 仅转账填写 |
| 金额 | 数字 | 正数，保留两位小数 |
| 币种 | 单选 | 默认 CNY |
| 分类 | 单选或文本 | 沿用用户现有分类 |
| 说明 | 多行文本 | 简短原始用途 |
| 状态 | 单选 | 有效、已撤销、已更正 |
| 关联记录ID | 单行文本 | 撤销或更正时指向原记录 |
| 创建时间 | 创建时间 | 由飞书生成或显式写入 |
| 更新时间 | 最后更新时间 | 由飞书生成或显式写入 |

### 每日随记

| 字段 | 推荐类型 | 规则 |
|---|---|---|
| 随记ID | 单行文本 | 唯一键，例如 `20260819-N01` |
| 日期 | 日期 | 随记日期 |
| 内容 | 多行文本 | 用户原意，不编造扩写 |
| 状态 | 单选 | 有效、已撤销 |
| 创建时间 | 创建时间 | 由飞书生成或显式写入 |

如果用户提供的表结构不同，优先映射现有字段，不擅自删除、改名或改变字段类型。缺少必需字段时，在获得用户授权后新增；无权限时列出缺失字段并停止写入。

写入前按记录 ID 查询去重，写入后按记录 ID 回读。飞书 API 或连接器返回成功但回读不到记录时，不宣称保存成功。

## 双写模式

双写时使用同一个记录 ID，推荐以飞书多维表格为主账本、Markdown 为便携备份：

1. 先写主账本并回读校验。
2. 再写备份并回读校验。
3. 两边均成功才回复“已记账”。
4. 只有一边成功时回复“部分保存”，明确成功端和失败端；重试时按记录 ID 幂等补写，不创建重复记录。
5. 同一 ID 内容冲突时不自动覆盖。展示日期、金额、账户等差异，请用户选择保留哪一版。

## 初始化与迁移

- 初始化新存储属于外部写入，先向用户确认目标位置或目标多维表格。
- 从 Markdown 导入飞书或从飞书导出 Markdown 时，先校验记录数、有效收入、有效支出、转账金额与净结余；全部一致后才报告迁移完成。
- 不在日志或回复中暴露访问令牌、密钥、Cookie 等凭据。
