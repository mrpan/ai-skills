# 记录规范

仅在需要分类、导出、查询或生成周月总结时读取本文件。

## 标准条目

每条记录包含：

- `id`：`YYYYMMDD-序号`，序号按当日当前对话中条目顺序递增，例如 `20260819-01`。
- `date`：`YYYY-MM-DD`。
- `kind`：`income`、`expense`、`transfer`、`note`、`void`。
- `account`：收入或支出的账户。
- `amount`：人民币金额，保留两位小数；随记无金额。
- `category`：分类。
- `description`：简短说明。
- 转账另含 `from_account` 和 `to_account`。
- 撤销另含 `voids`，指向被撤销条目 ID。

默认币种为人民币。用户明确使用其他币种时保留原币种，不自行换算；多币种汇总需分币种展示，只有用户提供汇率和日期时才换算。

## 建议分类

- 收入：工资、奖金、经营、利息、礼金、退款、其他收入。
- 备用金支出：家庭餐饮、家庭日用、住房、水电燃气、家庭通讯、家庭医疗、教育、育儿、赡养、家庭保险、人情、旅游、家庭娱乐、应急、其他家庭支出。
- 个人生活费支出：工作日餐饮、地铁公交、打车、个人通讯、化妆品、个人护理、服饰、个人购物、个人娱乐、其他个人支出。
- 家庭储蓄金：原则上不承担支出；明确发生支出时沿用实际用途分类，并标注 `储蓄金支出`。

用户自己的分类优先。分类不确定且不会影响账目时使用 `其他收入` 或 `其他支出`，不要为分类打断快速记录。

## 默认账户判断

用户未说账户时，按消费对象和用途判断：

| 表述或用途 | 默认账户 | 默认分类示例 |
|---|---|---|
| 家庭旅游、全家出行 | 备用金 | 旅游 |
| 买菜、家庭聚餐、家庭用品 | 备用金 | 家庭餐饮、家庭日用 |
| 房租、物业、水电燃气 | 备用金 | 住房、水电燃气 |
| 学费、培训费、孩子用品 | 备用金 | 教育、育儿 |
| 家庭成员医疗、家庭保险 | 备用金 | 家庭医疗、家庭保险 |
| 工作日早午晚餐 | 个人生活费 | 工作日餐饮 |
| 上下班地铁、公交、打车 | 个人生活费 | 地铁公交、打车 |
| 化妆品、护肤品和个人护理 | 个人生活费 | 化妆品、个人护理 |
| 个人服饰、个人娱乐 | 个人生活费 | 服饰、个人娱乐 |

“吃饭”“交通”“购物”等表述可能同时属于家庭或个人。消息中出现“全家、孩子、父母、家庭、家里”等线索时优先归备用金；出现“上班、通勤、我自己、工作日”等线索时优先归个人生活费。没有足够线索且账户会影响统计时再追问。

## 账本快照格式

```markdown
# 家庭资金账本快照

- 导出时间：YYYY-MM-DD HH:mm（时区）
- 币种：CNY
- 覆盖范围：YYYY-MM-DD 至 YYYY-MM-DD
- 有效记录：N 笔

| ID | 日期 | 类型 | 账户/流向 | 金额 | 分类 | 说明 | 状态 |
|---|---|---|---|---:|---|---|---|
| 20260819-01 | 2026-08-19 | 支出 | 个人生活费 | ¥28.00 | 餐饮 | 午饭 | 有效 |

## 校验汇总

- 收入：¥0.00
- 支出：¥28.00
- 转账：¥0.00（不计收支）
- 净结余：-¥28.00
```

快照必须包含全部范围内明细，而不只是汇总。若记录很多，可按月份分表，但不可省略条目。

## 周支出总结模板

```text
本周支出｜MM月DD日—MM月DD日（截至今天）

总支出：¥0.00｜共 0 笔

按账户
家庭储蓄金 ¥0.00
备用金 ¥0.00
个人生活费 ¥0.00

按分类
1. 分类 ¥0.00（0%）

最大支出
1. MM月DD日 说明 ¥0.00 · 账户

每日支出
周一 ¥0.00 … 周日 ¥0.00

转账：0 笔，¥0.00（不计支出）
随记：0 条
统计：YYYY-MM-DD 至 YYYY-MM-DD，有效支出 0 笔
```

没有交易的栏目可简化为“无”，但总支出、记录数和统计范围必须保留。分类占比以总支出为分母；总支出为零时不显示百分比。

## 月度收支总结模板

```text
YYYY年MM月收支（截至今天）

收入 ¥0.00｜支出 ¥0.00｜净结余 ¥0.00

按账户
家庭储蓄金：收入 ¥0.00｜支出 ¥0.00
备用金：收入 ¥0.00｜支出 ¥0.00
个人生活费：收入 ¥0.00｜支出 ¥0.00

支出分类
1. 分类 ¥0.00（0%）

最大五笔支出
1. MM月DD日 说明 ¥0.00 · 账户

较上月
收入 +¥0.00（+0%）｜支出 -¥0.00（-0%）

转账：0 笔，¥0.00（不计收支）
退款收入：0 笔，¥0.00
随记：0 条
统计：YYYY-MM-DD 至 YYYY-MM-DD，有效收入 0 笔，有效支出 0 笔
```

上月数为零时不要计算百分比，改为只展示金额变化。数据不完整时不要推断趋势。
