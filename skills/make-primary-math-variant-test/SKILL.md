# 小学数学错题变形测试卷

## 目标

把已确认的错题变成一张孩子能独立完成的测试卷：每道错题对应 2 道变形题，测的是同一个核心数学关系，而不是记住原题答案。测试卷只给孩子做，答案、来源和判读要点放在另一份答案卷里给家长。

## 确认输入

1. 优先使用 `$analyze-primary-math-papers` 报告末尾的“已确认错题清单”。清单已确认的，不再重复核对。
2. 用户直接给错题文字或照片时，先整理每题的来源题号、完整题干、孩子答案、正确答案和核心知识点，展示给用户确认；看不清的数字、符号、单位标为“待辨认”。**未得到用户明确确认前不出题**，不要靠题型猜原题。
3. 自己独立解一遍原题并复核答案。原题答案与用户或批改不一致时先说明并请用户核实，不据存疑的题出变形题。
4. 年级未知时，按原题内容判断难度，不必仅为年级追问。

## 出题规则

- **每道确认的错题出且只出 2 道变形题**，两道分工不同：
  - **第 1 道 · 同结构再练**：保持原题的核心数学关系和解题结构，换数据和情境，再加一个小变化，看孩子能否独立用可靠方法做对。小变化可以是边界值（如千万位正好是 5）、位数变化（如 1000000 减 1 变成六位数）、多问一步、数落在两格之间等。不能与原题一模一样或只换数字。
  - **第 2 道 · 变式辨析**：改变一个关键条件、问法或呈现方式，看理解是否稳固。依据错因假设选择形式——疑似理解问题，用“判断对错并说明理由 / 找出并改正错误”；疑似方法问题，换一种表示（数位表、线段图、列表、画图）或反向提问；疑似检查表达问题，用必须写单位、写验算或写答句才完整的题。
- 两道题都与原题同核心知识、同年级难度，不引入更高年级知识；计算量适龄，应用题符合常识，单位一致。
- 每题条件充分、答案唯一或评分口径明确。逐题独立求解并复核答案和步骤，避免无解、歧义。
- 数的书写遵循国内四位分级习惯，可写连续数字（如40108740），不用三位一组的英文逗号格式。
- 题面使用孩子能读懂的自然语言，不出现“粗心”“习惯差”“错因”等标签，也不在题面标注来源题号。

## 变形对比检查

每次出完题、组卷之前，把**每道变形题与它的原题逐项对比**，防止出错题，也防止变形跑偏。跑偏有两个方向：变得太多（换了知识点、超纲、难度大幅上升），或变得太少（与原题一模一样、只换数字）。两种都不通过。难度以“略升”为宜：在原题基础上加一点难度，但只加一个新难点。任一项不通过，就改题后重新对比；不通过的题不进入测试卷。

| 对比项 | 通过标准 |
|---|---|
| 核心知识点 | 与原题相同。原题陷阱本身对应的对照概念（如“改写”对“省略”）可以出现，但要注明；其他新知识点不加 |
| 年级与单元 | 术语、图形、方法都不超出原题所在的年级和单元 |
| 关键难点 | 保留原题中孩子出错的那一步（如“看千万位进 1”“同一直线上的线段算一条”），不能因简化而丢掉 |
| 解题步数 | 比原题最多多 1 步 |
| 数据规模 | 位数、数量级、计算量与原题相当，可略大，但不超出本单元的范围 |
| 改变幅度 | 不能与原题相同或只换数字；第 1 道在原结构上加一个小变化；第 2 道改变一个关键条件、问法或呈现方式；每道题新增的难点不超过一个 |
| 难度 | 以“略升”为宜；“持平”需说明与原题有什么不同；“略降”需说明关键难点仍然保留；不能“大幅升” |
| 正确性 | 用两种方法或正反两向独立求解，结果一致；条件充分，答案唯一；计数口径在题面写明，如几组平行线怎么算、“一共有几个角”时平角算不算 |
| 图文一致 | 图形按坐标核对：平行、垂直、刻度间隔、点的位置、角的类型都与题意和答案一致 |

- 数值题（改写、四舍五入、相邻数、按计数单位写数等）和图形坐标，能计算的都用代码或计算核对一遍，不只靠心算。
- 对比结果写进答案卷的“变形对比表”：每题列出原题、变形题、保留的关键难点、改变了什么、新增的难点、难度对比（略升 / 持平 / 略降）、核验方式、结论。

## 组卷

把所有变形题汇总成**一张测试卷**：

- 卷头：标题（如“数学错题巩固小测”）、姓名、日期、用时（可写“建议用时 __ 分钟”，按题量估算）、得分栏。
- 按题型分大题，顺序参照常见小学试卷：填空、判断、选择、计算、操作（画图/量一量）、解决问题。只保留实际用到的题型；大题编号用“一、二、三……”，小题全卷连续编号。
- 同一道错题的两道变形题尽量不相邻，避免孩子照搬上一题的做法。
- 每题留足书写空间：计算题、解决问题留出列式和验算的空白，填空题横线足够长。
- 不在测试卷上放答案、解析、来源题号或分值以外的提示。

## 交付

交付两份独立文件，放在同一个输出目录。目录名不带日期（如 `output/primary-math-variant-test/`），以后每次的卷子都放进这个目录；文件名以出题日期开头，如 `20261014-错题巩固小测.pdf`、`20261014-答案卷（家长用）.pdf`。同一天出第二份时，在日期后加序号（如 `20261014-2-错题巩固小测.pdf`），不要覆盖已有文件。

1. **测试卷**：A4 页面，黑白打印可读，合理分页（大题、图形不被页面截断），数学符号、分数、竖式和图形清晰。优先提供 PDF；若当前环境无法可靠生成或检查 PDF，提供自包含、带打印样式（`@page { size: A4 }`）的 HTML 并说明格式。
2. **答案卷**（给家长）：包含“变形对比表”（见上文）；按测试卷题号排列，每题列出——来源错题题号、对应第 1 道还是第 2 道、考查点、答案、简要解题步骤、判读要点。一题有多个空时，答案逐空写明名称（如“锐角 3 个，直角 3 个”），不要只写“3；3；2；1”这样的一串数字。判读要点写清作答怎样说明问题：规则解释或辨析持续错误，优先回到理解；理解正确但缺少可靠表示或方法，练方法；独立解答正确而屡次漏单位、符号或检查，才考虑表达与检查习惯。末尾附一张“来源错题 → 测试卷题号”对照表。

写完后逐项检查：题目总数等于确认错题数 × 2；每道错题恰有一道“同结构再练”和一道“变式辨析”；每道题都有变形对比结论且全部通过；测试卷题号与答案卷一一对应；答案、单位正确；测试卷中没有答案或来源信息。能渲染时查看实际打印页面；无法查看时明确说明只做了内容或结构检查。

## 批改复测

用户提交孩子的测试卷作答后，先按答案卷核对答案和过程，再按来源错题汇总：两道都对、只错一道、两道都错分别说明意味着什么。一次全对只说明本次表现，不保证已长期掌握；针对仍错的点给简短反馈，必要时建议过一段时间再测一次。题单与批改都不是心理或能力诊断。
